# Sneha Bharambe — Portfolio

A custom streaming-inspired recruiter portfolio built from Sneha's resume and provided LinkedIn URL. It is intentionally original and does not use Netflix branding or proprietary assets.

## Run locally
Open `index.html` directly, or serve the folder with any static server.

## Files
- `index.html` — semantic page structure and SEO metadata
- `styles.css` — responsive visual system and motion
- `script.js` — centralized project/skill data, carousel, modal, menu, reveal interactions
- `resume.pdf` — downloadable resume

## Content note
No GitHub link is shown because no GitHub profile URL was present in the provided resume or LinkedIn URL. Add it only when a verified URL is available.
